Open any Suikoden Tactics save container (.sps / .xps / .cbs / .max / .psu) or a raw PS2 memory-card image (.ps2). Party stats, equipment, runes, magic levels, recruitment (incl. the Suikoden IV hero unlock), gold, skill points and inventory are decoded from the verified field map; both game checksums (CRC-32 + MD5) are recomputed on write. Your file is processed locally and never leaves this device.

How this works & safety
This page runs the desktop editor's Python save code unchanged inside Pyodide (CPython compiled to WebAssembly). Your save is read into an in-memory filesystem, edited, and read back out for download — it is never sent to any server. Add this page to your Android home screen (browser menu → Install app / Add to Home screen) to use it offline. Always keep a backup of your original save.
